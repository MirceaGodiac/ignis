# F-NNN: short title

- **About:** C-… / D-… / M-… / X-… / page 2 classification of … / new
- **Reviewer:** exact model id (or name), date
- **Verdict:** confirmed | refuted | weakened | cannot tell | new
- **Severity:** integrity | model | record
- **Partitions touched while reviewing:** train only | validation inputs | other (say what, and
  whether it bars you from writing weights for the family)

## What the dossier says

Quote the claim, decision or classification in one or two lines, with the file and its id.

## What I did

The steps, in an order someone else can follow. Sources opened (with how much of each was read),
files read, scripts run.

## Evidence

Commands and their output, tables, or quotations with locators. For a train-only check, the
statement of what would count as confirming or refuting, written before the result.

## What should change

In the dossier, in a card, in a planned or carried model. If a model should change, say whether you
will write the candidate or propose that the author does.

## Response

(The author answers here: what was rerun, what was changed, or the disagreement and how it will be
settled.)
