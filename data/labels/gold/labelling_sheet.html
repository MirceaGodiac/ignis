R8 gold set: label by hand

Each card is one document of the stratified gold set (gold_template.jsonl). Fill the fields from the document itself, tick done, and export. Nothing here was filled or suggested by a model; the stratum shown is a file-name guess used only to pick the set, never a label. Your work is kept in this browser (localStorage) until you export.

Fields, closed values and rules
doc_type (one)
technical_report NASA TP/TM/CR or equivalent agency report · journal_article · conference_paper · presentation · thesis · requirements_document science requirements (SRD), test matrices · engineering_document hardware design, interface, verification · operations_document operations, procedures, timelines · data_description readme, data dictionary, file description · data_table experimental table or measurement file presented as a document · outreach · other
families (any)
flex · acme_normal · acme_inverse · bass · other. The experiment families the document is about; empty when none is clear.
investigation_ids (any)
PSI accessions the document is about, e.g. PSI-69, comma-separated; empty when none is clear. "Stored under" is only where the file sits: a document can be about another investigation, several, or none.
runs (any)
Run or test identifiers the document names, as written (e.g. FLEX-039, 19115A1), comma-separated. Mentions, not resolved identities. Scored case- and whitespace-insensitively.
conditions_mentioned (any)
pressure · mole_fraction · temperature · flow_velocity · gravity_level · mass_flow · volume_flow · std_volume_flow. Experimental conditions the document states.
Rules (the same the model is given)
Use only what the document shows; when unsure, other and empty lists. Never infer an accession from the topic alone. Read as much of the PDF as you need (the model sees only the outline and a few pages; the gold label is the truth about the whole document). Put edge cases and your reasoning in notes. Do not look at model labels for these documents before you finish.
When you are done
Export, save the file as data/labels/gold/gold_labels.jsonl (never over the template), commit it, then score a labeller with ignis evidence gold-eval --gold data/labels/gold/gold_labels.jsonl --labels <catalog dir>/source_labels.jsonl. Only rows marked done (with your name) are scored.
